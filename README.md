# 조달관 나르미 · NARUMI Procurement Quest

**2026 조달청 AI 게임·콘텐츠 공모전 (AI 게임 부문) 출품작**

카드 한 장으로 지키는 공공조달의 네 가지 가치 — 예산 · 공정성 · 혁신 · 국민만족.
조달관 나르미가 되어 12개월 동안 정책 카드를 좌우로 넘기며 결정을 내리는 Reigns형 의사결정 게임입니다.

## 바로 플레이

- GitHub Pages: <https://purplemacaron.github.io/narumi-procurement-quest/>
- 로컬 실행: `index.html`을 브라우저로 열면 즉시 실행됩니다. (설치·서버 불필요, `file://` 지원)

## 게임 소개

| 항목 | 내용 |
| --- | --- |
| 플레이 | 12턴(12개월) · 카드 60장 · 시나리오 6종 중 런마다 2종 조합 |
| 게이지 | 예산 · 공정성 · 혁신 · 국민만족 (0~100, 하나라도 0이면 조기 엔딩) |
| 엔딩 | 8종 (S/A/B 완주 4종 + 고갈 4종) |
| 수집 | 정책 도감 14종 · 업적 10종 · 최고 기록 저장 |
| 조작 | 카드 드래그 / 좌우 버튼 / 키보드 ← → |
| 저장 | localStorage 자동 저장 (도감·업적·엔딩·최고 기록) |

실제 조달 정책(혁신제품 시범구매, AI 전용 평가트랙, 나라장터, MAS 다수공급자계약 등)을
카드 이벤트와 정책 도감으로 풀어내어, 플레이하며 공공조달의 가치 균형을 학습할 수 있습니다.

## 기술 스택

- Vanilla JS (Classic script, 빌드 없음) · HTML5 · CSS3
- WebAudio 기반 SFX/BGM 폴백 신스 · 생성 미디어 에셋
- 모바일 우선 반응형 (max-width 520px) · `prefers-reduced-motion` 대응
- 결정적 RNG QA 훅: `index.html?seed=<정수>`

## 에셋 크레딧

- 캐릭터 나르미·달이 및 조달청 로고: 조달청 공식 캐릭터 (저작권자 © 조달청)
- 폰트: Pretendard (길형진), NeoDunggeunmo (Dalgona.) — 각 라이선스 파일 동봉
- 카드 아트·타이틀 배경·BGM·효과음·내레이션: Genspark API로 생성 (공모전 출품 목적)
